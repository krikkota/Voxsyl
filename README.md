# Voxsyl

Локальная голосовая диктовка для **macOS 14+ и Apple Silicon**.

Voxsyl работает в строке меню. Нажмите правый Option, продиктуйте текст и нажмите ещё раз: перламутровый индикатор преобразуется в редактируемый предпросмотр. Текст можно вставить в выбранное поле или сравнить с исходной расшифровкой.

## Скачать для Mac

Готовые сборки: [GitHub Releases](https://github.com/krikkota/Voxsyl/releases).

Распакуйте архив и перенесите `Voxsyl.app` в «Программы». Для записи нужен доступ к микрофону; для горячей клавиши и вставки — «Универсальный доступ» в настройках macOS. Текущая сборка имеет локальную подпись, без Apple Developer ID и нотариального заверения Apple: macOS может ограничивать запуск.

## Возможности

- Переключение записи нажатием или запись с удержанием клавиши.
- Локальное распознавание русской речи через GigaAM.
- Редактируемый предпросмотр и режим вставки сразу.
- Необязательное локальное редактирование текста через Qwen3.5-4B, с обязательным предпросмотром и сравнением с исходником.
- История текстов на 7 дней с возможностью отключить сохранение.
- Выбор микрофона и горячей клавиши, короткие звуки начала и конца записи.
- Запись до 4 минут с автоматической остановкой и обработкой.

## Модели и приватность

GigaAM INT8 включён в приложение. Корректор подключается отдельно: в Настройках выберите существующий `Qwen3.5-4B-Q4_K_M.gguf` из [сборки Unsloth](https://huggingface.co/unsloth/Qwen3.5-4B-GGUF), около 2,74 ГБ. Закреплённые версия, размер и SHA-256 находятся в [манифесте](benchmarks/artifacts.json). Файл используется без копирования. Автоматическая загрузка из настроек пока не реализована.

Распознавание и редактирование работают на устройстве. Нет аккаунтов, облачного API или отправки диктовки на внешний сервер. Аудиозапись обрабатывается в памяти; история содержит текст и хранится локально. Qwen запускается через встроенный llama.cpp и завершается после простоя.

Корректор может ошибаться: проверяйте смысл перед вставкой. Его текущий лимит — 3000 символов; при техническом сбое сохраняется исходный текст. Совместимость вставки зависит от приложения, защищённые поля исключены. Полный четырёхминутный сеанс и все сочетания устройств пока не прошли отдельную проверку.

## Происхождение и лицензия

Voxsyl использует открытые компоненты [Handy](https://github.com/cjpais/Handy), созданного CJ Pais и сообществом: аудиозапись, ресемплинг, визуализацию уровня и VAD. Основа — Handy v0.9.8, commit `14f6f0d31cb22a4268acfbddba3052820fd0a06e`; точные файлы перечислены в [UPSTREAM.json](app/UPSTREAM.json). Это целевая адаптация, а не полный импорт Handy. Спасибо авторам проекта.

Распознавание — [GigaAM](https://github.com/salute-developers/GigaAM) команды Сбера / GigaChat; редактирование — Qwen и квантование Unsloth; локальные движки — transcribe-rs, ONNX Runtime и llama.cpp; шрифт — Onest.
