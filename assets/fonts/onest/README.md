# Onest для макетов Voxsyl

Локальные начертания Regular (400) и Medium (500). Загружены 13 октября 2026 через официальный каталог Google Fonts. Источники конкретных файлов, размеры и SHA-256 находятся в `provenance.json`.

Оригинальная лицензия SIL Open Font License 1.1 сохранена в `OFL.txt` без изменений. Copyright 2021 The Onest Project Authors (https://github.com/googlefonts/onest).

Начертания не изменялись. Интерактивные макеты встраивают их через `data:`; сеть для показа шрифта не нужна. В конечном приложении файлы и лицензия должны поставляться локально. Утверждение типографики для приложения ожидает обсуждения макета.
