## Архив: Pearl Switch v1 — отклонён

Первая пара звуков, созданная 14 октября 2026 специально для Voxsyl. Пользователь запросил собственные короткие приятные сигналы включения и выключения диктовки. После прослушивания эта версия отклонена; сохранена для истории и сравнения.

| Файл | Назначение | Длительность |
|---|---|---|
| [voxsyl-activate-v1.wav](voxsyl-activate-v1.wav) | Мягкое раскрытие вверх: запись началась | 240 мс |
| [voxsyl-deactivate-v1.wav](voxsyl-deactivate-v1.wav) | Более тёплое движение вниз: запись закончилась | 210 мс |
| [voxsyl-switch-pair-v1.wav](voxsyl-switch-pair-v1.wav) | Прослушивание пары с паузой 700 мс; только демонстрация | 1,4 с |

Идея — короткий округлый стеклянный перелив с мягкой нижней опорой и слабым блеском, соответствующий материалу «Перламутр». Включение раскрывает звук, выключение собирает его. Второй сигнал синтезирован отдельно, а не получен простым проигрыванием первого задом наперёд.

Синусоидальные слои и короткие отражения созданы процедурно. Чужие записи, сэмплы, мелодии и ресурсы системных ассистентов не используются. Глобальная акустическая уникальность не проверена и не гарантируется.

## Технические данные

WAV PCM 16 bit, 48 кГц, stereo; небольшой запас ширины с сохранением центрального сигнала. Пик обоих файлов около −10 dBFS; RMS −20,85 / −21,35 dBFS. Файлы не перегружены, первый и последний сэмплы нулевые, начала и окончания сглажены. Измерения и SHA-256 сохранены в [provenance.json](provenance.json).

Числовая проверка не заменяет прослушивание через встроенные динамики Mac и наушники. Комфортную громкость в приложении, узнаваемость на тихом уровне и отсутствие утомления при частом использовании проверяем при интеграции.

## Воспроизведение исходников

Нужны Python 3 и NumPy только для повторного синтеза:

```sh
python3 assets/sounds/pearl-switch/generate.py
```

Готовое приложение воспроизводит сохранённые WAV; генератор и Python ему не требуются. Для точного повторения версия NumPy записана в provenance. Скрипт создаёт только файлы в своём каталоге.

Это собственные материалы проекта; окончательная лицензия собственного кода и ресурсов пока не выбрана. Внешних аудиолицензий и требований атрибуции сэмплов нет. Интеграция и поведение описаны в [docs/sound-identity.md](../../../docs/sound-identity.md).
