# Локальный стенд моделей

Стенд для разработки; это не пользовательский интерфейс Voxsyl. Все тексты и WAV обрабатываются локально. Скрипты не открывают микрофон. Python нужен только для разработки стенда/сборки, не для запуска готового `.app`.

Результаты и ограничения: [отчёт 14 октября](../docs/benchmark-results-2026-10-14.md).

Требуется Apple Silicon, Python 3.12+, Rust stable. Текущие готовые библиотеки требуют macOS 14+. Запускать из корня проекта.

```sh
python3 benchmarks/prepare.py
python3 benchmarks/build_asr.py
python3 benchmarks/llm_bench.py --output outputs/benchmarks/cleanup-local.json
```

`prepare.py` скачивает только публичные артефакты из manifest, проверяет размер/SHA перед использованием. `--offline` запрещает скачивание; `--only gigaam,ort` выбирает конкретные компоненты; `--include-comparisons` добавляет большие модели сравнения. Кеш находится в `.cache/`, в Git не включается.

Полный путь для своего **явно указанного** WAV (16 kHz, mono, PCM16):

```sh
python3 benchmarks/audio_bench.py path/to/test.wav --output outputs/benchmarks/my-audio.json
```

Отчёт содержит распознанный текст; не публикуйте отчёт с личным аудио по ошибке. Для своих файлов предусмотрен игнорируемый каталог `benchmarks/private-audio/`. Это инструкция для разработчика, не согласие записывать микрофон.

Повтор эксперимента с 4B после `prepare.py --only qwen3-4,llama,gigaam,ort`:

```sh
python3 benchmarks/audio_bench.py path/to/test.wav \
  --model .cache/benchmark/models/Qwen3-4B-Instruct-2507-Q4_K_M.gguf \
  --prompt benchmarks/prompts/edit-plan-v1.txt --edit-plan --temperature 0.2 \
  --output outputs/benchmarks/my-plan.json
```

Runner сам запускает/останавливает свой llama-server, использует случайный loopback-порт, одноразовый ключ и `--offline`. Интернет нужен только при явной подготовке файлов. В ограниченной среде Metal может требовать разрешения исполнения; CPU-проверка доступна через `llm_bench.py --cpu`.

`prepare_audio.py --synthesize` создаёт синтез Milena из собственного текста на macOS. Сначала убедиться, что голос установлен и WAV не пуст. Без этого флага скрипт использует уже созданный `miki-tts.wav`. Повторяющиеся 30/120-секундные файлы служат только измерению затрат; `--asr-only` профилирует их с чанками до 20 с. Фиксированная нарезка не является готовым алгоритмом сегментации речи.

```sh
python3 -m unittest discover -s benchmarks -p 'test_*.py' -v
```

Планы замен — эксперимент. Ограничение буквальными фрагментами снижает возможность лишних изменений, но не доказывает смысловую правильность. Любая отклонённая замена откатывает весь план; незавершённая генерация и оставшиеся признаки оговорки требуют исходного предпросмотра. Нормализованное совпадение с эталоном — диагностическое поле, не оценка точности.
